# HackArena

HackArena is a LeetCode-style coding practice platform designed to help programmers hone their problem-solving skills. Built by a team of passionate developers, this project mimics LeetCode's functionality, providing an interactive space to practice algorithmic challenges in a clean and user-friendly interface.

## Features
- **Code Editor** – Solve algorithmic problems with a built-in coding environment.
- **Problem Sets** – A collection of coding challenges to practice and improve skills.
- **User Authentication** – Secure login and personalized problem-solving history.
- **Minimalist UI** – Intuitive and easy-to-use interface inspired by LeetCode.

## Tech Stack
- **Frontend:** React, TailwindCSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Code Execution:** Docker, Judge0 API
